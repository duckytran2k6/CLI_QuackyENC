# **Welcome to QuackyENC 🦆,**

📥 This is a very basic open-source multi text files encryption tool where you can encrypt and decrypt fully offline right 
on your local OS terminal. The purpose for this project is to learn the process of files encryption and combine it with 
the CLI features, allowing the users to use the tool in a plain simple way. The reason for that is because QuackyENC focuses 
on security, simplicity, and flexibility as the program has been modified in order to be able to run and compatible for 
upload/download files on different OS. QuackyENC uses the secure AES algorithm with GCM mode more efficiency and RSA algorithm
for hybrid cryptosystem, adding more layers into the authentication for more security.

## ✅ **Features:**
### **This is a list of features of what QuackyENC included with a short description for each of them:**

- #### _**Password-based file encryption:**_ 
This is the most basic and simple encryption method which only requires a password that is provided by the user which will be used 
for that specific whole session. For decryption part, the user will be required to provide a salt file along with the password in 
other to derived from them to retrieve the secret key which will be used with the IV in order to decrypt the encrypted files.

- #### _**Key pair-based hybrid encryption:**_
This is a bit more complicated method which will required the sender and the receiver to have a matched key pair generated by the 
Key-Pair generator. As the way of how it will work, the receiver will generate his own key pair using the generator that will return 
a public key file and private key file. Then, the receiver will provide the sender the **public key file** in other to encrypt the files. 
Finally, in order to decrypt, the receiver will have to use the **private key** a long with the encrypted secret key + IV file which the program will 
check if the key pair is matched or not then proceed. Even though this method is more complicated than the password-based, it is more secure
since it reduces the chance of being attack and break by brute-force through adding more layers into authenticate the information between the 
sender and receiver.

- #### _**Key-Pair Generator:**_
This will generate a random 2048 bits key pair using RSA algorithm including a public key and a private key that can be used to check for
matching validity between the sender and the receiver. This is required if you are using the **_Key pair-based hybrid method_** as you will need
to generate the key pair before using the method.
**❗THE RECEIVER MUST KEEP THE PRIVATE KEY SAFE. DO NOT SHARE THIS, ONLY SHARE THE PUBLIC KEY TO THE SENDER.❗**

- #### _**Supports multiple files encryption:**_
QuackyENC allows you to upload up to 20 text files to be encrypted in one session. Although, this comes with some limitations which is available
with more information by running `-info` command.

- #### _**CLI with file select GUI:**_
The tool is supported with a small file picker window which automatically pops up whenever the user execute the command for either encryption or
decryption.

- #### **_Compress files:_**
The tool, by default, will automatically compress all the files into a final zip file that will automatically download to the user's OS Download folder once
the process is finished.
