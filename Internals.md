# **Internals**

This document provides an overview of QuackyENC's internal design. It contains the details on things such as the cryptography algorithms
in use, how I/O is managed, and different layers of processing within the tool. The goal is to give a clear understanding on both high-level
user-interaction logic and the low-level cryptography operations that help ensure the security and compatability for the tool.

# **Core Cryptography**

QuackyENC uses the following algorithms from the Security and Crypto classes:
* AES-GCM: Both methods use Advanced Encryption Standard (AES) which is a symmetric-key encryption algorithm with the Galois/Counter
Mode (GCM) for higher efficiency.
* RSA: Stands for Rivest-Shamir-Adleman, which is a different algorithm from AES by having a pair of keys. Used to perform cryptography
operations on the Secret Key and IV generated by the AES.
